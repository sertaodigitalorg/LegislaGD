# Documentacao

Este diretorio concentra arquitetura, governanca, implantacao, integracoes, seguranca, roadmap e ADRs do LegislaGD.

Para subir a plataforma central legislativa aberta em desenvolvimento local, comece por `implantacao/desenvolvimento-local.md`.

## Atendimentos e comunicacao

- `sigi-sd/comunicacao-unica-camara.md`: desenho tecnico local para Atendimento Unico, canais oficiais, importacoes, acessos e checklist visual.
- `sigi-sd/PENDING_SYNC.md`: sincronizacoes funcionais pendentes quando nao houver acesso direto ao Drive.
- `portalmodelo/migracao-conteudo-site-original.md`: roteiro para migrar informacoes do Portal Modelo original para o PortalModelo-SD local.

## e-Cidade-SD
