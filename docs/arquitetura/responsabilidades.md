# Responsabilidades e autoridades de dados

> **Classificação:** HÍBRIDO  
> **Autoridade funcional:** Google Drive  
> **Autoridade técnica:** GitHub

As responsabilidades de domínio abaixo refletem a arquitetura técnica do LegislaGD e devem permanecer alinhadas às fichas funcionais vigentes no Google Drive.

- **SAPL-SD:** autoridade dos dados e atos legislativos oficiais dentro de seu domínio.
- **Plenario-Digital-Core:** mantém apenas estado operacional próprio e dados derivados; não substitui sessão, presença, votação, voto, resultado ou demais dados legislativos oficiais do SAPL.
- **e-Cidade-SD:** autoridade dos dados administrativos, financeiros e funcionais pertencentes ao GRP conforme módulos habilitados na implantação.
- **PortalModelo-SD:** publica conteúdo institucional e informações públicas, sem se tornar autoridade dos dados originados em outros sistemas.
- **SIGI-SD:** autoridade dos protocolos, histórico de atendimento e dados próprios de relacionamento/orquestração; não incorpora regras de negócio dos sistemas especializados.
- **LegislaGD:** governa a integração e a operação conjunta, sem duplicar a autoridade interna dos componentes.

Mudanças de responsabilidade funcional devem ser validadas primeiro no MASTER do Drive. Mudanças de mecanismo técnico de integração são registradas no GitHub e em ADR quando relevante.
