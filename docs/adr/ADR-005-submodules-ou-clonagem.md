# ADR-005: Submodules ou clonagem

## Decisao

Nao adicionar Git submodules automaticamente na fase inicial.

## Contexto

Submodules amarram revisoes com precisao, mas aumentam complexidade operacional para equipes e implantacoes.

## Consequencias

Usaremos scripts de clonagem inicialmente. A migracao para submodules pode ocorrer por decisao formal futura.
